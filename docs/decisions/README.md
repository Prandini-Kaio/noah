# ADRs — registros de decisões arquiteturais

Criar `000X-titulo.md` ao adotar uma decisão com consequências duradouras: convenção de coordenadas, formato de projeto, armazenamento e integrações.

Modelo:

```markdown
# ADR 000X — Título
Status: Accepted | Proposed | Superseded
Data: AAAA-MM-DD
Contexto:
Decisão:
Alternativas consideradas:
Consequências / trade-offs:
Como validar:
```

E1 exige pelo menos um ADR antes de fechar interfaces numéricas e de persistência.
