# Dataset sintético E1
reference-rgb.ply foi criado neste projeto, sem capturas ou dados de terceiros,
e é disponibilizado sob CC0-1.0. Três pontos XYZ e cores primárias conhecidas.
Para a demo, o usuário declara referencial destro Z-up; unidade permanece Unknown.
Escala 2, rotação Z π/2, translação (3,4,5) resulta aproximadamente em
(3,6,9), (1,4,5), (3,4,5); tolerância absoluta 1e-12.

`inspection-box.obj`: caixa sintética de 2×3×4 unidades de cena, 8 vértices e
12 triângulos, gerada para E4; CC0-1.0. Ângulo A2–B1–C4 = 90°. Distância
2–1 = 2 u. cena; declarar 200 mm nessa aresta fornece dimensões 200×300×400 mm.
O arquivo não codifica unidade física nem orientação física validada.
