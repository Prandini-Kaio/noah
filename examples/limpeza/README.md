# Exemplo de limpeza — CC0-1.0
348 pontos sintéticos: grade cúbica de 343 pontos em [0,0.6]³ e 5 pontos isolados
em (3,3,3) até (7,7,7), em vermelho. Unidade desconhecida.
Importe nuvem-com-outliers.ply, selecione e abra Limpar nuvem → Editar nuvem.
SOR: k=16, sigma=2; ou raio=0.2, mínimo=3. Revise a prévia e aplique.
Esperado para esses parâmetros: 5 candidatos, 343 mantidos. Desfazer restaura 348.
Seleção por caixa [0,0,0]–[0.3,0.6,0.6]: 196 pontos.
O PLY isolado não contém câmeras: serve para edição, não para Delaunay. Para
superfície limpa, use a nuvem sparse aberta a partir do run das fotos do kit.
