# Kit de refinamento E6 — CC0-1.0
As mesmas 12 imagens sintéticas de examples/pipeline/fotos, separadas em base
(10) e adicionais (2), sem alteração dos bytes. hashes.json registra integridade.
Reconstrua base em um run novo. Selecione esse run e use Adicionar fotos para
processar base + adicionais em outra revisão. Compare as duas por câmeras comuns.
Não são capturas físicas novas nem validação metrológica; são dados de teste.
O reprocessamento pode variar contagens e não garante melhoria de qualidade.
