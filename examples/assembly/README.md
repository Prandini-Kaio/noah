# Montagem de demonstração

Geometria sintética CC0-1.0, criada no NOAH: base, suportes, mancais, eixo,
volante, anel e manivela. Dez componentes em coordenadas já montadas. Unidades
arbitrárias, sem validação mecânica, tolerâncias ou metrologia. A vista explodida
é uma disposição visual, não uma sequência física de desmontagem.
