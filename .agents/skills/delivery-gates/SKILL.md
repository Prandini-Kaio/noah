# Skill: validação de entrega

1. Compare alterações com o plano do MVP atual.
2. Execute (se possível) fmt/clippy/testes; liste exatamente o que passou ou falhou.
3. Reproduza demo com dataset documentado.
4. Verifique persistência/identidade/unidades, entradas inválidas e dados brutos.
5. Confira docs, ADRs, dependências e licenças.
6. Apresente checklist de aceite: conforme, pendente, bloqueado; sem mascarar falhas.
7. Proponha próximo MVP sem implementá-lo.
